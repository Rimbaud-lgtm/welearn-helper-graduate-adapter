# WeLearn Edge 安装与升级

版本：0.3.8-preview.1。启动请求由后台确认接收后弹窗才关闭；确认接收不等于练习已完成。同步授权与目录队列，支持空正文页10秒后继续；长文本框接受最长2000字符的唯一课件参考。B1U1 Writing Ex.3只在明确识别课件唯一示范引言及其说明标记时读取正文作为候选，不把它视为所有写作题的标准答案。系统只记录时间的项目不报告正确率。短词填空仍限制160字符；多个答案、无可靠参考、草稿冲突或输入回读不一致都不能提交。关闭 Codex 后重启 Edge、真实断网恢复及全课程覆盖尚未验收，因此仍为预览版，不是正式稳定版。

## 首次安装

1. 解压发布 ZIP 到固定目录，例如 `D:\Tools\WeLearnPractice\extension`，保留此目录。
2. 在 Edge 地址栏打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择直接包含 `manifest.json` 的目录。
4. 固定扩展图标，打开设置，保存核验间隔、批量偏好和是否允许替换未提交草稿。
5. 登录 WeLearn，打开目标课程目录，再打开扩展设置。目录必须识别为225项，已有完成项不可授权重做。
6. 保存设置；首次独立验收只选择一项未完成的选择/词汇填空题，提交上限1，点击“授权所选练习”。未取得扩展自身真站判分及目录对账前，不能授权多项。

首次独立验收在扩展内部执行输入验证、一次提交和目录对账；不是 Codex/PowerShell 代操作。候选来自当前合法课件DOM的唯一参考，不请求第三方答案。没有唯一候选时记为待处理，在启用跳过策略后继续寻找授权范围内的其他练习；不猜测、不提交。填写匹配率不是答案正确率；结果只有答题时间的任务不报告百分比。支持题型及判分门控仅根据扩展自身真站记录保存，不以单元测试或以往Agent操作解锁。

## 再次使用

打开 Edge，登录课程目录，点击扩展中的“开始练习”。扩展内容脚本和后台完成目录扫描、填写/逐字符核对、预设授权提交、结果读取及目录完成数对账。无需 PowerShell、npm、Python 或本地服务。真实热启动流程已经验证；关闭 Codex 后的冷启动验收仍待执行，不能混为一项通过。

也可以在已打开的练习页点击开始/继续：存在课程授权时，先通过原生返回读取目录，再寻找授权范围内未完成项。当前题无可靠候选或不支持时不提交；当前题不在范围内也不会扩大授权。额度耗尽时需重新明确授权。连接、会话或完成状态不明时暂停，不强行跳题。

点击开始/继续或当前练习的填写验证后，扩展弹窗会自动关闭，焦点交回课程窗口；这不是崩溃。启动交接有短超时，后续每次写入仍要求课程标签激活、所在窗口聚焦，切到其他窗口会暂停。填写验证只核对输入，不提交；课程目录需使用“开始练习”，不能把目录当作输入验证页。

不支持题型、无可靠候选及草稿冲突在已保存跳过设置下保留为待处理；网络、登录、会话异常或提交结果不明立即暂停。开始、暂停、继续、停止均在扩展内执行。重启后任务暂停，用户点击继续，提交过但结果不明的记录不能重提。浏览器恢复后的目录已完成记录会只读对账。授权额度耗尽需再次明确授权，扩展不会自动扩大范围。

正文页只有在加载完成且确认没有练习控件后才开始10秒倒计时；随后使用平台原生导航返回目录并继续。存在题目或仍在加载的页面不能算作无练习。不要同时打开第二个学习课件；切换到其他窗口会保护性暂停。

有分数的首次验收通过后，可以一次选择剩余未完成项并设置累计授权上限，以及每批1至10项的执行上限。授权范围/累计额度与每批数量分开保存；每批结束再次点击开始即可继续消耗已有授权，不必每日运行开发命令。新输入类型可先单独授权1项进行验证，未经验证的类型不能在普通批次中提交。

后台缓存可能在闲置后消失，授权和启动会由扩展重新扫描目录，不要求用户执行外部命令。相关平台机制见 [Chrome extension service-worker lifecycle](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。

## 关闭 Codex 的验收

1. 首次配置保存后关闭 Codex，正常关闭并重新打开 Edge。
2. 登录并打开目标课程目录，仅点击一次“开始练习”，不要启动其他学习会话。
3. 等待该项填入、原生判分、返回目录；检查完成数是否只增加1，以及任务记录是否出现“扩展执行”和“目录已对账”。
4. 使用“下载执行记录”保留本地JSON。记录包含扩展版本、浏览器启动时间、执行阶段时间、实际结果和提交计数，不含Cookie、密码、答案或账户标识。
5. 返回汇报结果后核实JSON及页面证据；未做这一检查就标记UNVERIFIED。安装/代码测试不是此项验收。

## 升级

暂停任务，将新包覆盖到原来的安装目录，然后在 `edge://extensions` 点击此扩展的“重新加载”。保留同一安装目录并且不卸载扩展，以保留本地设置和任务账本。升级会保留提交中的不确定状态；必须先回读系统结果，不能重试提交。

## 数据

设置、匿名任务标识和系统回读结果存储在当前浏览器的扩展本地存储。扩展不读取 Cookie、密码，不联网调用第三方答案服务，不同步个人数据。卸载扩展会清除扩展本地数据。只读公开课件参考内容用于形成候选，系统判分仍是正确率唯一依据。

安装方式依据 [Microsoft Edge 官方侧载说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。正式商店分发和自动升级需要后续发布到 Edge Add-ons。
