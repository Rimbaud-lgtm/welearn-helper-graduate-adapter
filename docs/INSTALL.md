# WeLearn Edge 使用文档

版本：**0.3.9-preview.3**。适配《新时代研究生学术英语：综合教程1》，`cid=2850`，官方目录225项。其他课程、手机App和录音上传不在适配范围。

## 1. 安装

准备支持扩展侧栏的新版 Microsoft Edge，以及能够正常访问课程的本人账号。扩展不提供账号或课程权限。

1. 从 [发布页](https://github.com/Rimbaud-lgtm/welearn-helper-graduate-adapter/releases) 下载 `welearn-edge-0.3.9-preview.3.zip` 和对应 `.sha256` 校验文件。
2. 解压到固定位置，例如 `D:\Tools\WeLearnPractice`，安装后不要删除或移动该目录。
3. 在Edge地址栏输入 `edge://extensions`，打开“开发人员模式”。
4. 点“加载解压缩的扩展”，选择直接含 `manifest.json` 的文件夹，不选ZIP或还需要再进入一层的目录。
5. 固定 **WeLearn Practice Assistant** 图标，正常登录WeLearn，打开官方课程目录。只保留一个学习课件。
6. 点击扩展图标打开常驻侧栏，核对版本、课程和目录完成数。未连接时等页面加载后点一次“重新识别”。

安装和重载方式依据 [Microsoft Edge官方侧载说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。目前未上架Edge Add-ons，不提供商店自动升级。GitHub自动生成的Source code ZIP是源码，不能代替安装包。

## 2. 首次运行：只授权一项

新浏览器没有验证记录，不能通过复制别人的日志解锁批量功能。

1. 保持课程目录打开，在侧栏点“设置”。
2. 首次不启用批量，“每批上限”为1；“允许替换未提交的草稿答案”建议保持关闭。点击“保存设置”。
3. 在“提交授权”中选择 **1项未完成的选择或词汇填空练习**，“授权提交上限”为1，点击“授权所选练习”。已完成项不可选。
4. 返回课程标签，点一次“开始练习”。保持Edge在前台，不重复点击开始、不反复刷新、不打开第二个学习会话。
5. 等待填写、输入核验、原生提交、系统结果与目录完成对账。
6. 如遇不支持、候选不足、只读或冲突，项目会留待人工；这不算成功验收。尝试其他受支持单项前，先确认没有提交结果不确定的记录。

需取得扩展自己的原生提交、数值判分和目录对账证据，才允许扩大范围。只有保存时间的项目不能替代首次计分验收。未验证的输入类型可能继续被拦截，不能修改能力标记来绕过验证。

## 3. 批量与累计授权

首次验收通过后重新打开设置，确认已显示自主判分与目录对账证据。

| 设置 | 含义 |
|---|---|
| 批量处理已确认未完成的练习 | 允许多项处理 |
| 每批上限 | 1至10项 |
| 自动接续下一批 | 批末自动继续，仍受原累计授权限制 |
| 不支持的题型保留待人工处理 | 记录不支持原因并跳过 |
| 允许替换未提交的草稿答案 | 明确允许覆盖冲突草稿，默认建议关闭 |
| 每项核验间隔 | 核验配置；实际等待还取决于页面事件与系统响应 |

先保存设置，再勾选练习或点“选择全部未完成练习”，填写**累计提交上限**，点“授权所选练习”。运行中不要修改授权。

例如选30项、累计上限20、每批10项并自动接续，最多消耗20次授权提交。跳过不消耗提交次数；已有成绩不重做。批次之间不需要反复确认，“每批10”也不代表无上限提交。恢复暂停时不要反复重新授权。

返回课程，点“开始练习”。后续填写、核验、提交、判分、返回和进入下一项均由扩展完成，日常使用不需要Codex、PowerShell、Python、Node.js、本地服务或API Key。

## 4. 读懂侧栏

- **回读完成 X/225**：最近一次成功读取的官方目录。加载期间保留上次值。
- **核验输入 X/Y**：填写内容与候选一致的数量。参考框可能不计分，不能当作系统正确数。
- **本题系统正确率**：系统实际返回的数值；“仅记录完成”表示只有保存时间。
- **新增完成**：当前一次运行相对启动时目录的变化。手动继续可能新建运行，因此不是整天累计数。
- **授权余额**：上限减已消耗提交次数。结果不明时可能已消耗额度，不能清空账本恢复额度。
- **本轮跳过 / 待人工**：跳过包含无题正文；待人工排除目录已完成项，两者不必相等。

正文只有在加载完成且确认无练习控件后才等待10秒，再正常返回。平台可能将正文记为学习完成，但它不产生题目正确率。

## 5. 暂停、继续与错误

“暂停”停止后续处理；“继续”重新核对页面与原授权；“停止”结束当前运行。关闭侧栏不等于暂停。恢复前不要删除扩展数据、重置成绩或反复点击原生Submit。

| 提示 | 处理 |
|---|---|
| 未连接 / CONTENT_NOT_LOADED | 确认唯一目标课件、等加载后重新识别一次 |
| NOT_FOREGROUND | 回到课程标签并使Edge在前台，核对状态后继续 |
| NO_CANDIDATE | 无唯一可靠候选，留待人工，不猜测提交 |
| UNSUPPORTED_TYPE | 录音、作品或不支持控件留待人工 |
| READ_ONLY_FIELD | 不强改页面属性，保留待办 |
| FIELD_ID_INVALID | 重复或无法唯一定位的题目标识，保留待办 |
| DRAFT_CONFLICT | 默认保留已有草稿，需要覆盖时应明确设置许可 |
| ENGINE_TIMEOUT | 查看实际页面是否已加载、是否已有提交结果，再重新识别并继续，不重提 |
| SESSION_ENDED | 先检查真实登录/并发学习提示；正常目录切换也有误标的已知问题，先查目录和日志 |
| UNCERTAIN_SUBMIT | 只读检查系统结果和目录，未确认前不能重试或重置额度 |
| 授权范围内无可自动处理项 | 可处理队列已遍历，剩余项可能待人工，不代表全225项完成 |
| 额度用完 | 停止；只有用户另行决定扩大范围/额度才重新授权 |

预览版可能在慢导航超过约45秒后暂停；延迟目录事件或终态页面变化还可能显示SESSION_ENDED。以系统结果、官方目录和每项提交计数对账；“开始已接收”不等于答题成功。不要反复刷新或清空扩展数据处理会话错误。

## 6. 日志与数据

“下载执行记录”生成 `welearn-extension-audit-时间戳.json`。包含版本、课程题目标识、进度、成绩、执行时间、提交计数与错误；导出格式不含密码、Cookie、账号原文或答案正文，但成绩和时间仍属个人学习记录。

日志不会自动上传。[仓库历史日志](https://github.com/Rimbaud-lgtm/welearn-helper-graduate-adapter/tree/main/docs/runtime-logs)经所有者明确授权公开。反馈前请检查自己的文件；日志是诊断快照，**不是可导入备份**，不能恢复授权或解锁验证能力。

扩展本地存储还保存课程/账号的散列绑定、授权、输入类型验证与提交账本。不调用第三方答案服务，不用私有接口修改成绩、学习时长或完成标记。

## 7. 升级与下次使用

1. 暂停任务，先对账任何提交结果不确定的项目。
2. 新安装ZIP覆盖**原安装目录**；不要卸载扩展或切换浏览器配置文件。
3. 在 `edge://extensions` 点重新加载，或在扩展设置点“应用已安装的更新”。后者仅重载本地文件，不会下载新版。
4. 重载可能关闭侧栏，返回课程重新打开；先重新识别，核对版本、余额及旧完成记录，再继续。

下次使用只需Edge、正常登录课程、打开侧栏并开始/继续。关闭Codex后重启Edge的独立冷启动、真实离线/崩溃恢复尚未验收，不据此承诺无人值守稳定运行。MV3后台可能休眠，内存连接缓存和持久化账本不同，参见 [官方后台生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。

## 8. 源码构建

需要Node.js 20或更高版本：

```powershell
npm ci
npm run build
```

加载 `dist/edge`，不要直接加载 `extension/`（缺少构建生成的共享适配器及图标）。开发者完整检查用 `npm test`；Windows打包用 `pwsh -NoProfile -File tools/package.ps1`。
